This week focuses on Advanced Python for Data Analysis, where you will strengthen your ability to
manipulate data, perform time-series analysis, and engineer features that help uncover meaningful
insights from real-world data.

Objective

To apply advanced Python techniques for data transformation, time-series analysis, and feature
engineering using historical stock market data.

Dataset

Use the Apple Inc. (AAPL) Historical Stock Market Dataset from Yahoo Finance.
Dataset Link:

https://finance.yahoo.com/quote/AAPL/history/

This task requires you to use python

Install yfinance in your python environment

Ipip install yfinance

Dataset Features

The dataset contains:
• Date
• Open Price
• High Price
• Low Price
• Close Price
• Adjusted Close Price
• Trading Volume

Topics to Cover

• 1. Data Transformation with Pandas

Apply advanced Pandas operations such as:

• Data cleaning
• Handling missing values
• Filtering and sorting data
• Grouping and aggregation
• Creating calculated columns
• Data formatting and restructuring


• 2. Time-Series Analysis

Perform time-based analysis including:

• Date and time manipulation
• Trend analysis
• Daily and monthly performance analysis
• Rolling averages (7-day, 30-day, or other suitable periods)
• Percentage change analysis
• Time-based visualizations
• 3. Feature Engineering Basics

Create meaningful features such as:

• Daily Price Change
• Percentage Price Change
• Moving Averages
• Monthly Returns
• Volatility Measures
• Any additional features that improve analysis
