Objective
Apply the complete data analytics workflow to solve a real-world problem and communicate your
findings through professional documentation, visualization, and presentation.
Step 1: Dataset

Data Source

https://datatopics.worldbank.org/world-development-indicators/

How to Download the Dataset
• Click on the link above.
• Scroll down the page until you see Access Data.
• Under Access Data, locate Bulk Downloads.
• Click CSV Download.
• Download the file named WDI_CSV.zip.
• Extract the ZIP file.
• Use the main CSV file contained in the extracted folder for your analysis and dashboard
development.

About the Dataset
The World Development Indicators (WDI) is the World Bank's flagship collection of global
development statistics. It contains a wide range of indicators covering over 200 countries and
territories across themes such as:
• Economy
• Poverty and Inequality
• Education
• Health

• Environment
• Infrastructure
• Trade
• Technology
• Governance

Step 3: Perform Data Cleaning
Prepare your dataset for analysis by:

• Handling missing values
• Removing duplicates
• Correcting inconsistencies
• Standardizing data formats
• Creating calculated columns where necessary
• Documenting all cleaning steps performed

Step 4: Conduct Data Analysis

Analyze the dataset to identify:
• Trends and patterns
• Relationships between variables
• Significant changes over time
• Key Performance Indicators (KPIs)
• Meaningful comparisons and insights

Step 5: Create Visualizations and Dashboard

Develop an interactive and professional dashboard using Power BI.
Your dashboard should include:

• Key Performance Indicators (KPIs)
• Charts and Graphs
• Filters/Slicers
• Clear Labels and Titles
• Consistent Formatting and Design

Ensure that your visualizations effectively communicate your findings.
